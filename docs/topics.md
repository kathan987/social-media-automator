# Topic backlog (explainer series)

Each explainer Short answers ONE question about ONE character. This file is the backlog of those questions, in story
order. No fact is trusted until it has two sources in the project's `research.md`.

## How a character gets its questions
1. The agent reads the character's wiki page and official pages, then proposes 10-15 questions or hidden details. Each
   comes with the two source URLs for every fact and the moment in your footage that proves it (mission or episode
   name and a timecode).
2. You approve, drop or reorder the list.
3. Each Short takes the next unmade question. Mark it done here with the project folder name.

## Source order for facts
1. The thing itself (a cutscene, a line of dialogue).
2. The publisher's official pages.
3. A wiki (second source, never the only one).
